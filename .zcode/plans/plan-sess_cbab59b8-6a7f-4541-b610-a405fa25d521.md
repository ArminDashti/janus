## 9. MCP enable toggle + platform cascade

**Types (both mirrors):**
- `McpResource.enabled: boolean`.
- `AppSettings.mcpEnabled?: Record<string, boolean>` (key = MCP name, matches the merged-row identity; absent ⇒ enabled).

**Scanner (`scanner.service.ts`):**
- Set `enabled: settings.mcpEnabled?.[name] ?? true` when pushing MCPs.
- `probeMcps()` skips servers with `enabled === false` (no process spawn).

**Cascade (`platform-sync.service.ts`):** new `applyMcpEnableCascade(previous, next, current)` — for each platform whose `enabled` flipped: newly **enabled** → read its `mcp.json`, set each server name `true`; newly **disabled** → set its server names `false` **only if** no still-enabled platform defines the same name. Wire into `PUT /api/settings` (`routes/index.ts:83–105`): when `platformsChanged`, compute `settings.mcpEnabled = await applyMcpEnableCascade(...)` **before** `settingsStore.save(settings)`.

**UI (`McpsPage.tsx`):**
- New "Enabled" column with a `Toggle` per row; handler saves `{ ...settings, mcpEnabled: { ...map, [name]: !enabled } }` via `window.agentManager.saveSettings` (settings from `useAppStore`), then `loadSettings()` + `refreshScan({ probeMcps: true })`.
- Row with `enabled === false` shows a neutral "disabled" badge instead of the probe status.
